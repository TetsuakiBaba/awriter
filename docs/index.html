AWriter

打ち間違えない役者。

文字を打つ場面を撮るための macOS 用エディタです。打たせたい内容を台本に書いて再生すると、本物の日本語入力を通してそのとおりにタイプします。このページはその使い方をひととおり説明するマニュアルです。

01AWriter とは

映像のなかに、誰かが文字を打っている画面が必要になることがあります。製品のデモ、操作を説明するチュートリアル、劇中でノートパソコンに向かう一場面。

いざ撮ろうとすると、これが厄介です。打ち間違える。変換が思ったところで確定しない。緊張して指が止まる。AWriter は、その一点のためだけに作った macOS 用エディタです。書くための道具ではありません。

  • 押すキーを台本に書いておくと、そのとおりに打ちます。打鍵の間隔にはゆらぎが入るので、機械が吐き出しているようには見えません
  • かなを漢字に変えているのは macOS の日本語入力そのものです。未確定の下線も候補ウィンドウも、画面に映るのは本物です
  • 「再生前に本文を消去」で頭から撮り直せます。カメラの位置を変えても同じ芝居が返ってきます
  • 書類の管理をしません。保存の確認も、編集済みの表示も出ません。ウィンドウの名前は自由に決められ、空にすればタイトルは出ません
  • カーソルも変換中の下線も選択範囲も無彩色です。アプリ由来の色味が絵に入りません
  • 書類ウィンドウだけを mp4 に録画できます。背景を敷いて余白付きで浮かせる絵も、アプリの中で作れます

アクセシビリティの許可は要りません。AWriter は自分自身のイベントキューにキーイベントを送っているだけで、他のアプリを操作することはできません。

02インストール

配布は GitHub Releases です。Developer ID で署名し、Apple の公証を通してあるので、ダウンロードしたものをそのまま開けます。右クリックから開くような回避操作は要りません。

  1. 最新のリリースから AWriter-バージョン.dmg をダウンロードします。
  2. dmg を開き、AWriter.app を「アプリケーション」フォルダへドラッグします。
  3. アプリケーションフォルダから AWriter を起動します。起動するとエディタウィンドウと台本エディタが一緒に開きます。

動作環境

  • macOS 14 以降
  • Apple シリコン / Intel の両方で動くユニバーサルバイナリ
  • 日本語を打たせるなら、macOS 標準の日本語入力(「日本語 - ローマ字入力」)を入力ソースに入れておきます

画面収録の許可

録画機能を初めて使うときだけ、macOS が「画面収録」の許可を求めます。

許可したあとは AWriter を一度終了して、起動し直してください。許可はプロセスの起動時に読まれるため、許可した直後のプロセスには反映されません。未許可のまま録画しようとすると、システム設定の該当ペインを開く案内が出ます。

03画面の構成

ウィンドウは二つだけです。撮影に映るのは書類ウィンドウ、操作するのは台本エディタ、という役割分担になっています。

書類ウィンドウ(映る側)

1タイトルバー。名前は台本エディタの「ウィンドウ名」で決めます。空にすれば何も出ません
2「あぁ」ボタン。フォント・文字サイズ・文字色・外観の設定がここにまとまっています
3本文カラム。ウィンドウをどれだけ広げても最大 720pt で、つねに中央に置かれます
4変換中の下線。macOS の日本語入力が引いている本物です
5文字数カウンタ。書類ウィンドウの一部なので、録画にも映ります

台本エディタ(操作する側)

アプリ起動時に一緒に開きます。閉じてしまったら デモ > 台本エディタ…(⌥⌘P)で開き直せます。

A再生と録画、「再生前に本文を消去」、ウィンドウ名、キー表示・録画設定、台本の読み書き
B台本のタブ。+ で追加、ダブルクリックで名前を変更、× で削除
Cトークンのボタン。押すとカーソル位置に挿入されます
D台本の本文。等幅で表示され、アプリ内に自動保存されます
E記法の早見表。書き方を忘れてもここを見れば済みます

04文字組みを整える

映像に映る以上、文字そのものが商品です。設定は書類ウィンドウ右上の「あぁ」ボタンにまとまっています。項目は四つだけです。

項目内容
フォントヒラギノ明朝(既定)/ 凸版文久明朝 / 游明朝体 / ヒラギノ角ゴシック / 凸版文久ゴシック / ヒラギノ丸ゴ / 筑紫A丸ゴシック / クレー / システムフォント / New York。お使いの Mac に入っているものだけが並びます
文字サイズ12〜36pt。行送りは 1.7 倍、段落後のアキは 0.4em で、サイズに追従します
文字色自動(ライト / ダークに追従)、墨・煤竹・紺青・海老茶・千歳緑・胡粉の和色、任意のカスタムカラー
外観システム / ライト / ダーク。撮影の途中でシステム設定が切り替わって地の色が変わる事故を防げます

文字色を「自動」以外にしたら、外観もライトかダークに固定してください。暗い地に墨色を置くと読めなくなります。

設定はアプリ内に保存され、次に起動したときも同じ状態で始まります。本文も同じように保存されるので、書きかけがそのまま残ります。

05台本を書く

台本は押すキーをそのまま並べたものです。文章を書くのではなく、キーボードでどう打つかを書きます。ローマ字の並び、変換のためのスペース、候補の選択、確定の {enter}。ローマ字からかな、かなから漢字への変換は AWriter ではなく IME が行うので、台本には「どのキーを押したか」だけを書きます。

# 冒頭のカット(夏目漱石『草枕』)
#lead 3
#interval 100
#jitter 0.35

{kana}{wait 0.5}
yamamichiwonoborinagara,koukangaeta.{space}{enter}
{wait 0.8}
{enter}
chinihatarakebakadogatatu.{space}{enter}

ディレクティブ

行頭に # で書きます。台本全体にかかる設定です。# で始まるその他の行はコメントとして無視されます。

書き方意味
#lead 3再生を押してから打ち始めるまでの秒数。カメラを回す間
#interval 100基本のキー間隔(ミリ秒)。小さいほど速く打ちます
#jitter 0.35間隔のゆらぎ率。人間らしいリズムになります。0 で機械的に等間隔
#speed 1.0全体の速度倍率。台本を書き直さずに尺を詰められます

トークン

特殊なキーは波括弧で書きます。台本エディタのボタンからも挿入できます。

トークン押されるキー
{enter}Return。変換の確定、または改行
{space}スペース。かなの変換、候補送り
{tab} {esc} {bs}Tab / Escape / Delete(1 文字削除)
{up} {down} {left} {right}矢印キー。候補の選択や文節の切り直しに
{kana} {eisu}かなキー / 英数キー。入力モードの切り替え
{wait 0.5}0.5 秒待つ。間を作る
{cmd+n} {shift+enter} {cmd+shift+z}修飾キーの組み合わせ。cmd shift ctrl opt を + でつなぎます

書くときのきまりごと

  • 通常の文字は 1 打鍵ずつ送られます。yama と書けば y・a・m・a の 4 打です
  • 台本の生の改行はキーを送りません。読みやすさのために好きなところで折り返せます。改行させたいときは {enter} と明示します
  • 日本語を打たせるなら、先頭で {kana} を送って入力モードを確実にしておきます
  • 変換候補の選び方も台本に書きます。スペースを連打する、{down} で送る、数字キーで選ぶ、いずれも書けます

タブと読み書き

台本はアプリ内に自動保存されます。保存の操作は要りません。タブで何本でも持てるので、シーンごと、言語ごと、尺の長短ごとに用意しておいて、撮影の場で切り替えられます。

  • + で追加、ダブルクリックまたは右クリック > 名前を変更でリネーム、× で削除、右クリック > 複製
  • インポート… は .keys ファイルを新しいタブとして読み込みます
  • エクスポート… はいま開いているタブを .keys に書き出します。ファイル操作は保存のためではなく、受け渡しのためのものです

06再生する

  1. 台本エディタで、打たせたい台本のタブを選びます。
  2. 撮り直しのために本文を空にしてから始めるなら、「再生前に本文を消去」にチェックを入れます(既定はオン)。消去は ⌘Z で元に戻せます。
  3. 再生を押します。書類ウィンドウが前面に出て、#lead の秒数だけカウントダウンしてから打ち始めます。
  4. 再生が終わるまで、キーボードとマウスに触れません。

止める

ESCいちばん確実。再生中に効く唯一のキーです
停止ボタン台本エディタの赤いバナー、またはフローティング HUD
⌥⌘.メニューの デモ > 停止

途中で止めると、未確定の変換中テキストは破棄されます。

再生中の表示

再生中であることが一目で分かるよう、次の表示が出ます。

  • フローティング HUD — 常に最前面に浮かぶ小さな表示。点滅する赤い点、カウントダウン、進み具合、停止ボタン。キーフォーカスを奪わないので、これを操作しても変換は壊れません。ドラッグで動かせて位置は記憶されます。撮影に映り込むなら、台本エディタの「再生中の表示を最前面に」をオフにします
  • 台本エディタ — 赤いバナーとウィンドウ全体の赤枠。再生中は本文の編集とボタンがロックされます

07キー入力を見せる

チュートリアルを撮るときは、押されたキーを画面に重ねて表示できます。⇧↩ のように修飾キーまで出るので、見ている人に操作が伝わります。既定はオフです。設定は台本エディタの「キー表示」ボタンから。

項目内容
表示するキーすべてのキー(連続するローマ字はひと続きの札にまとまります)/ 特殊キーのみ(修飾キー付きの操作と特殊キーだけ)
位置カーソル位置 / 左下 / 下中央 / 右下 / 上中央
大きさ14〜44pt
残す時間0.5〜5 秒

「カーソル位置」を選ぶと、札が挿入点のすぐ下に付いて動きます。端では自動的に内側へ寄り、下に入らなければ上に回ります。打つ・変換する・確定する、という流れがそのまま読み取れます。

台本の合成キーも手打ちも同じ経路を通るので、自動再生でも手で打っても同じように表示されます。札は書類ウィンドウの一部なので、録画にもそのまま映ります。

08録画する

台本エディタの「録画して再生」を押すと、書類ウィンドウを録画しながらデモを再生します。再生が終わると録画も自動で止まり、トリミング画面が開きます。外部の画面収録アプリは要りません。

  • 出力は H.264 / mp4(音声なし)。解像度は書類ウィンドウの実ピクセル(Retina なら 2 倍)
  • 映るのは書類ウィンドウの中身だけです。手前に台本エディタや HUD が重なっていても映りません。逆に、キー入力の札と文字数カウンタは書類ウィンドウの一部なので映ります
  • 録画中は書類ウィンドウのリサイズができません(録画の解像度は開始時に固定されるため)
  • マウスカーソルは既定で映りません。デモ > マウスカーソルを録画に含めるで切り替えます
  • 止め方は再生の停止と同じです。録画だけ止めたいときは デモ > 録画停止(⌥⌘R)

背景を付ける

「録画設定」から、書類ウィンドウを背景の上に余白付きで浮かせて録画できます。このページの冒頭の映像がその絵です。

  • 背景 — 画像か単色を選びます。画像はアプリ内にコピーされ、キャンバスに合わせて中央基準で切り取られます。未選択なら暗いグラデーションになります
  • プレビュー — 設定した縦横比そのままの枠で、余白・角丸・影・ウィンドウの位置まで確認できます。書き出しサイズも下に出ます
  • ウィンドウを拡大しないぶん、書き出しはウィンドウより大きくなります(860×680 のウィンドウ・余白 8%・16:9 なら 2878×1618)。背景は静止しているので、H.264 ではほとんど容量を食いません

トリミングと書き出し

録画が終わると自動でトリミング画面が開きます。

  • プレビューを再生しながら、フィルムストリップ上の 2 つのハンドルで開始点と終了点を決めます。ストリップのクリックでシーク、「ここを開始に」「ここを終了に」で再生ヘッドの位置をハンドルに送れます
  • 「録画して再生」はカウントダウンより前から回っているので、頭の余白はここで落とす前提です
  • 解像度はオリジナル / 1080p / 720p。高さを基準に、横は元の比のまま合わせます。元より大きくは書き出しません
  • 「書き出し…」で保存先を選ぶと mp4 を書き出します。カット位置はキーフレーム境界ではなくフレーム単位で正確です
  • 素材は一旦アプリの中に置かれ、書き出すか破棄すると消えます

録画中は macOS がタイトルバーに画面共有のインジケータを出します。書類ウィンドウを切り出して録るので、これも一緒に映ります(冒頭の映像の左上に写っている小さなピルがそれです)。気になる場合は、書き出したあとに動画編集で上端を切ってください。

09撮影のこつ

  • 本番前に必ず一度リハーサル再生する。変換結果は IME の学習状態に依存します。意図と違う変換になった箇所は、候補選択のキー({space} の追加や {down})を台本に足すか、一度手で正しく変換して IME に覚えさせます
  • ライブ変換はオフを前提に台本を書く。オンだと挙動が変わり、台本どおりの見た目になりません
  • 再生中は AWriter を前面のままにする。他のアプリにフォーカスが移ると、変換中のテキストは破棄され、以降のキーも届きません
  • 再生中はキーボードに触れない。効くのは ESC(停止)だけです
  • 撮影のあいだシステムの外観が切り替わらないよう、外観はライトかダークに固定しておきます
  • 通知やスクリーンセーバが入らないよう、集中モードを入れておくと安全です
  • 間の取り方は {wait} で作れます。台詞に合わせて止める、考えるふりをする、といった芝居も台本の側で決められます

10ショートカット

キーはたらき
⌥⌘P台本エディタを開く(デモ > 台本エディタ…)
ESC再生を止める
⌥⌘.再生を止める(デモ > 停止)
⌥⌘R録画だけ止める(デモ > 録画停止)
⌘Z「再生前に本文を消去」で消えた本文を戻す

11困ったとき

録画しようとすると許可を求められ、許可しても録画できない

画面収録の許可は、プロセスの起動時に読まれます。許可したあとに AWriter を一度終了して起動し直してください。

台本どおりの漢字にならない

変換しているのは macOS の日本語入力なので、その学習状態がそのまま出ます。リハーサル再生で確認し、候補選択のキーを台本に足すか、手で一度正しく変換して覚えさせてください。ライブ変換はオフを推奨します。

途中でローマ字のまま出てしまう

入力モードが英数になっています。台本の先頭や、モードが変わりうる箇所で {kana} を送ってください。

再生が途中で止まる、途中から入力されない

他のアプリにフォーカスが移った可能性があります。再生中は AWriter を前面のままにしてください。

台本エディタを閉じてしまった

デモ > 台本エディタ…(⌥⌘P)、またはウィンドウメニューから開き直せます。台本は自動保存されているので消えていません。

HUD が撮影に映り込む

台本エディタの「再生中の表示を最前面に」をオフにしてください。なお HUD は書類ウィンドウの録画には映りません。

台本を別の Mac に持っていきたい

エクスポート… で .keys に書き出し、向こうで インポート… します。
