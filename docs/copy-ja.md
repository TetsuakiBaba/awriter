# AWriter 紹介文(日本語)

Web サイトや紹介映像で使う文案。映像で実際に打たせる台本は [scripts/intro.keys](../scripts/intro.keys)。

**読み手**: 映像を作る人。製品デモやチュートリアルを撮る開発者、プロモーション映像の制作者、劇中に画面が映る映画・ドラマの美術。

---

## キャッチコピー

> **打ち間違えない役者。**

副案:

- テキストを打つシーンを、一度で撮る。
- そのカット、何度でも同じに打てます。
- 撮影のためだけのエディタ。
- 台本どおりに、指が動く。

---

## リード文(映像で実際に打たせる本文)

```
このエディタは、書くためのものではありません。

文字を打つ場面を撮るための、道具です。
台本を書いておけば、そのとおりに打ちます。
打ち間違いも、変換のもたつきもありません。

いま画面に出ている変換も、本物の日本語入力です。
同じ芝居を、何度でも。
```

短く使う場合は最初の三行まで。

## 製品説明(サイト本文)

### 撮り直しをなくす

映像のなかに、誰かが文字を打っている画面が必要になることがあります。製品のデモ、操作を説明するチュートリアル、劇中でノートパソコンに向かう一場面。

いざ撮ろうとすると、これが厄介です。打ち間違える。変換が思ったところで確定しない。緊張して指が止まる。カメラを回しているあいだ、演者は台詞を言いながら正しくタイプし続けなければなりません。たいてい何度も撮り直すことになります。

AWriter は、その一点のためだけに作った macOS 用エディタです。

### 台本を書いて、再生する

打たせたい内容を、あらかじめ台本として書いておきます。ローマ字の並び、変換、候補の選択、確定。押すキーをそのまま書き並べる形式です。

再生を押すと、三秒のカウントダウンのあと、エディタが台本どおりに打ち始めます。打鍵の間隔にはわずかなゆらぎを入れてあるので、機械が吐き出しているようには見えません。速度も、間の取り方も、台本の側で決められます。

### 変換は本物

かなを漢字に変えているのは、macOS の日本語入力そのものです。AWriter は再現をしていません。

だから画面に映るのは本物です。未確定の文字列に引かれる下線も、変換候補が並ぶウィンドウも、文節を切り直す動きも、確定した瞬間の見た目も、実際に起きていることがそのまま撮れます。候補をスペースで送る、矢印で選ぶ、番号で選ぶ。そうした操作も台本に書けます。

### 何度でも同じ芝居を

「消去して再生」を押せば、本文を空にしてもう一度、頭から。カメラの位置を変えて撮り直しても、同じ芝居が返ってきます。

台本はタブで何本でも持てます。シーンごと、言語ごと、尺の長短ごとに用意しておいて、撮影の場で切り替えられます。

### 画面に映るものだけを残した

撮影では画面そのものが絵になります。余計なものは全部外しました。

- **ウィンドウの名前は自由**。空にすればタイトルバーには何も出ません。作中の書類名を入れることもできます
- **書類の管理をしません**。保存の確認も、変更済みの表示も、増えていくボタンもありません
- **カーソルも、変換中の下線も、選択範囲も無彩色**。アプリ由来の色味が絵に入りません
- **本文は窓の中央に一定の幅で組まれます**。窓を広げても行が間延びしません

### 文字組み

映像に映る以上、文字そのものが商品です。

**書体** — お使いの Mac に入っている日本語書体から選びます。ヒラギノ明朝、凸版文久明朝、游明朝体、ヒラギノ角ゴシック、凸版文久ゴシック、ヒラギノ丸ゴ、筑紫A丸ゴシック、クレー。

**大きさ** — 12 から 36 ポイント。行間と段落の間隔は選んだ大きさに追従します。

**色** — 墨、煤竹、紺青、海老茶、千歳緑、胡粉。任意の色も指定できます。

**外観** — ライトとダークを固定できます。撮影の途中でシステム設定が切り替わって地の色が変わる、という事故が起きません。

### キー入力を見せる

チュートリアルを撮るときは、押されたキーを画面に重ねて表示できます。`⇧↩` のように修飾キーまで出るので、見ている人に操作が伝わります。

札は画面の四隅に固定するほか、入力中のカーソルに追従させることもできます。連続するローマ字はひと続きの札にまとまるので、打つ・変換する・確定する、という流れがそのまま読み取れます。

### 撮影者のための表示

再生中は、常に最前面に小さな表示が浮かびます。カウントダウン、進み具合、停止ボタン。撮影に映り込むなら消せます。
